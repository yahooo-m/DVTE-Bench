Overview

Evaluation beyond bottom-aligned subtitles

DVTE-Bench isolates difficult cases hidden by aggregate scores: moving overlays, vertical writing, distributed regions, title cards, persistent marks, and non-bottom layouts.

Every source clip has a clean target and a temporally aligned mask. Target frames were scanned under one OCR audit configuration; confirmed residual text caused rejection. All eight text types, including ASR subtitles, contribute to the same 1,631-video aggregate.

Protocol

A reproducible evaluation contract

Evaluate every clip consistently against its paired clean reference and pixel-accurate mask.

01

Load paired clips

Read source and target at native frame alignment. Use the provided mask for region metrics.

02

Report mask region

Measure Mask PSNR, SSIM, LPIPS, DISTS, VFID, TWE, TC, and flow statistics.

03

Evaluate all clips

Compute the primary leaderboard over the complete set of 1,631 benchmark videos.

04

Break down by type

Report all eight text categories separately to expose category-specific strengths and failures.

Target-side OCR audit

All target frames were scanned with a fixed configuration. 569 candidates with confirmed target text were rejected before the final 1,631-sample release.
