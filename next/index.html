Report every slice.

All eight categories contribute to the full aggregate. Per-type results reveal where performance changes.

Clean-target audit. All target frames were scanned under one OCR configuration. 569 candidates with confirmed residual text were rejected before the final release.

Dataset composition. 1,563 clips use synthetically overlaid text; 68 form the seen ASR regression track with known training overlap. The full 1,631-video aggregate and category results retain both tracks.

Inference settings. Ours uses a 40K checkpoint, 6 inference steps, GT bounding-box guidance, and seamless paste-back. ProPainter, MiniMax-Remover, and DiffuEraser use GT box masks with source paste-back; CLEAR is mask-free. Metrics use pixel-accurate GT masks. The qualitative outputs include each method’s saved postprocessing.
